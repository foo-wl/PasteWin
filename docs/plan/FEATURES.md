## 一、参考界面拆解（来自 macOS Paste 截图）

```
┌───────────────────────────────────────────────────────────────────────────┐
│              [🔍 Clipboard History ▾] [● jetbrains] [+]              (...)│  ← 顶部栏
├───────────────────────────────────────────────────────────────────────────┤
│ ┌──────────────┐┌──────────────┐┌──────────────┐┌──────────────┐         │
│ │文本   3分钟前 ││文本   3分钟前 ││文本   3分钟前 ││文本   3分钟前 │         │  ← 卡片 header(56px, 彩色)
│ │      [icon]●││      [icon]●││      [icon]●││      [icon]●│         │     右上：来源 App 图标 + 色点
│ ├──────────────┤├──────────────┤├──────────────┤├──────────────┤         │
│ │AdGuard for   ││Apple Safari  ││AdGuard       ││uBlock Origin │         │  ← 卡片 body（白底横线纸纹）
│ │Safari        ││浏览器        ││              ││Lite          │         │
│ │              ││              ││              ││              │         │
│ ├──────────────┤├──────────────┤├──────────────┤├──────────────┤         │
│ │⌘1   18个字符 ││⌘2   16个字符 ││⌘3    7个字符 ││⌘4   18个字符 │         │  ← 卡片 footer
│ └──────────────┘└──────────────┘└──────────────┘└──────────────┘         │
└───────────────────────────────────────────────────────────────────────────┘
```

要点（Windows 版沿用）：
- 窗口：无边框、圆角（12px）、半透明背景、下方投影；点击外部自动隐藏（失焦 hide，非销毁）
- 卡片尺寸：约 168×190 px，间距 10px，横向排列 + 横向滚动
- 卡片 header：背景色 = Pinboard 颜色（默认按来源 App 分类着色）；左上类型名 + 相对时间；右上 App 图标 + 圆形色标
- 卡片 body：白底 + 横线纸纹（`repeating-linear-gradient`），文本预览 3–5 行，超出省略
- 卡片 footer：序号（`1`…`9` 对应 `Ctrl+数字` 直选）+ 数量后缀（文本"18个字符"/图片"128 KB"/文件"3个文件"）
- 选中态：2px 蓝色描边 + 轻微放大阴影；键盘左右移动时卡片自动滚入视野
- 顶部栏：搜索胶囊（占位符显示当前钉板名）、钉板 tab 列表（带颜色圆点）、`+` 新建钉板、右侧 `...`（暂停记录/清空/设置/退出）

## 二、P0 功能详述

### 1. 常驻与托盘
- 启动后无主窗口，仅托盘图标。
- 托盘左键单击 = 打开/关闭面板（可配置）；右键菜单：`打开` / `暂停记录（30 分钟 / 直到恢复）` / `清空历史…` / `设置…` / `退出`。
- 关闭面板 ≠ 退出进程。首次关闭给出气泡提示。

### 2. 全局热键
- 默认 `Ctrl+Shift+V`；可在设置中改为 `Alt+V`、`Ctrl+\``、`双击 Ctrl`（修饰键双击）。
- 绑定失败（被占用）时弹窗提示并列出 3 个建议组合。
- **不可用**：`Win+V`（系统剪贴板历史独占）、`Ctrl+V`、`Ctrl+C`。

### 3. 剪贴板捕获
| 格式 | 读取方式 | 展示 |
|---|---|---|
| 纯文本 | `CF_UNICODETEXT` | 原文，保留换行 |
| 富文本 | `HTML Format` + `Rich Text Format` | header 标"富文本"，body 显示纯文本，粘贴时按原格式回写 |
| 图片 | `PNG` / `CF_DIBV5` / `CF_BITMAP` | 缩略图（最长边 320px），header 标"图片"，footer 显示尺寸 + 体积 |
| 文件 | `CF_HDROP` | 文件名列表（最多 4 个 + "等 N 个"），header 标"文件" |
| 链接 | 文本且以 `http(s)://` 开头 | header 标"链接" + 域名 favicon 替代 App 图标 |

- 忽略：空内容、超阈值（默认文本 > 1 MB / 图片 > 20 MB，可配）、自身写入的回环。
- 排除：前台窗口进程命中黑名单（默认含 `KeePass.exe` `1Password.exe` `Bitwarden.exe` `keepassxc.exe`）→ 丢弃不落库。

### 4. 去重与排序
- 主键：`sha256(kind + 规范化内容)`。命中则 `use_count++`、`created_at` 刷新、卡片置前。
- 默认排序：`pinned DESC, created_at DESC`。Pinboard 视图内按该钉板过滤。

### 5. 面板交互（纯键盘可达）
| 按键 | 行为 |
|---|---|
| 热键 | 打开面板并聚焦搜索框，默认选中第 1 张卡片 |
| `←` `→` | 移动选中卡片 |
| `Enter` | 粘贴选中项到原窗口并关闭面板 |
| `Ctrl+Enter` | 以纯文本粘贴 |
| `Ctrl+1..9` | 直接粘贴第 N 张 |
| 直接输入 | 进入搜索，实时过滤（150ms 防抖） |
| `Tab` / `Shift+Tab` | 切换 Pinboard |
| `Delete` | 删除选中项 |
| `Ctrl+P` | 收藏/取消收藏 |
| `Esc` | 关闭面板 |
| 双击卡片 | 粘贴 |
| 右键卡片 | 上下文菜单：粘贴 / 纯文本粘贴 / 复制回剪贴板 / 收藏 / 移动到钉板 / 删除 / 查看详情 |

### 6. 回写与粘贴注入
1. 记录面板唤起前的前台窗口 `HWND` 与焦点控件。
2. 打开剪贴板（带重试，最多 5 次 × 30ms，应对被占用）。
3. 写入全部可用格式（文本条目同时写 `CF_UNICODETEXT` + `HTML Format`，图片写 `PNG` + `CF_DIB`）。
4. `SetForegroundWindow(hwnd)` 恢复目标窗口（失败则 `AttachThreadInput` 兜底）。
5. `SendInput` 发送 `Ctrl+V`（或 `Shift+Insert` 降级）。
6. 目标窗口为提权进程（UIPI 拒绝）时，面板底部提示"目标窗口权限更高，需以管理员身份运行"。

### 7. 搜索
- 输入即搜，`items_fts` 匹配 + 来源应用名匹配。
- 支持前缀即搜、大小写不敏感、中文子串（trigram）。
- 空结果给出提示 + "清除筛选"。

### 8. 设置
分组：通用（开机自启、语言、主题）/ 快捷键 / 历史（条数、天数、体积上限、启动时清空）/ 隐私（排除应用列表、禁用图片记录）/ 存储（DB 路径、导出、清空）/ 关于（版本、更新）。

## 三、P1 功能详述

### 9. Pinboards（钉板）
- 每个钉板有：名称、颜色（12 色预设）、图标（emoji 或自定义图片）、排序。
- 顶部 tab 栏顺序展示；点击切换；`Tab` 循环切换。
- 拖拽卡片到 tab = 归档到该钉板。
- 每个钉板可绑热键（`Ctrl+Shift+1..9`）直接唤起该视图。
- "最近使用"为默认虚拟钉板，不可删除。

### 10. Snippets（片段/模板）
- 独立管理页：名称、内容、可选热键。
- 触发方式：热键直接粘贴；或搜索时输入 `;名称`。
- 支持占位符 `{date}` `{time}` `{clipboard}`（粘贴时求值）。

### 11. Paste Stack（顺序粘贴队列）
- 勾选多条 → "加入队列" → 之后每次 `Ctrl+Shift+V` 依次粘贴下一条，粘贴完自动出队。
- 面板内可查看队列进度、重排、清空。

### 12. 多选与批量
- `Shift+点击` 区间选择、`Ctrl+点击` 加选、`Ctrl+A` 全选。
- 批量：合并粘贴（以 `\n` 连接）/ 收藏 / 移动钉板 / 删除。

### 13. 类型智能识别与差异化展示
- 链接 → 显示域名 + 页面标题（不发网络请求，仅用剪贴板 `CF_HTML` 里的 `<title>`）。
- 颜色值（`#RRGGBB` / `rgb()` / `hsl()`）→ 卡片显示色块 + 点击复制。
- 代码片段 → 等宽字体 + 语法高亮（轻量 `shiki` 或 `highlight.js`，仅 8 种常用语言）。
- 文件路径 → 识别存在性，双击在资源管理器打开（可选）。

### 14. 自动更新
- `tauri-plugin-updater` + 静态 JSON manifest（可放 GitHub Releases）。
- 检查间隔 24h，静默下载，重启生效。

## 四、P2 功能（规划，不进首版）

| 功能 | 说明 |
|---|---|
| 云同步 | WebDAV / OneDrive 增量同步，冲突以 `created_at` 为准 |
| 团队钉板 | 共享只读钉板（链接形式） |
| 脚本扩展 | 条目绑定 PowerShell 脚本，热键执行 |
| 高级搜索 | `app:chrome type:image before:2026-10-01` |
| 拖拽导出 | 卡片直接拖到资源管理器/邮件客户端 |
| 多语言 | 中/英，i18n 键值化 |

## 五、非功能指标

| 指标 | 目标 |
|---|---|
| 热键 → 面板首帧可见 | < 120 ms |
| 捕获到落库 | < 20 ms |
| 10 万条记录关键词查询 | < 50 ms |
| 常驻内存（空闲） | < 90 MB |
| 安装包体积 | < 15 MB |
| 冷启动到托盘就绪 | < 800 ms |
| 历史容量 | ≥ 10 万条（可配） |
| 数据安全 | 本地存储，可选 SQLCipher 加密；排除列表强制不记录 |
